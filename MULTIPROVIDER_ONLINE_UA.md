# Mornye Play — MultiProvider Online (експериментальна Beta 3)

Підтримка онлайн-відтворення через **Qobuz Online**, **Jellyfin Online**
та **SoundCloud Online** з однієї кнопки ▶. Відтворення здійснюється у
вбудованому плеєрі без попереднього завантаження файлу.

## Склад пакета

| Джерело | Версія розширення | Якість | Авторизація |
| --- | --- | --- | --- |
| Qobuz Online | 1.2.29 | FLAC, можливий Hi-Res | Підписана сесія й підтвердження доступу, якщо потрібне |
| Jellyfin Online | 1.1.2 | Оригінальний файл (FLAC/MP3/інші формати) або MP3/Opus транскодування | Власний Jellyfin сервер із HTTPS та дійсним обліковим записом/API-ключем |
| SoundCloud Online | 1.0.15 | Найкращий доступний публічний AAC/MP3/Opus (не FLAC) | Лише треки, позначені сервісом як доступні для повного прослуховування |

**Необхідні два компоненти:** новий Mornye Play ARM64 APK
та відповідні модифіковані `.sflx` файли. Звичайні Jellyfin/SoundCloud
розширення з офіційного каталогу ще не мають функції `resolvePlaybackStream`.

## Використання

1. Установіть MultiProvider APK **Mornye Play** (`com.famous37.mornyeplay`).
2. Відкрийте **Settings → Extensions**. Установіть і ввімкніть
   `jellyfin.sflx`, `soundcloud.sflx` та, якщо потрібно, `Qobuz Online 1.2.29.sflx`.
3. Для Jellyfin відкрийте налаштування розширення й укажіть **HTTPS Server URL**,
   ім'я користувача та пароль або дозволений API-ключ. Натисніть **Test connection**.
4. Натисніть ▶ біля треку або альбому. Якщо він отриманий із Jellyfin чи
   SoundCloud, застосунок спочатку пробує відповідне джерело.
   Якщо потрібний сервіс недоступний, інші ввімкнені розширення можуть
   спробувати знайти точний відповідник.
5. Довге натискання ▶ відкриває вибір якости. **Best available** означає
   найкращу якість, яку реально пропонує конкретне джерело.
   Jellyfin підтримує Original, MP3 320/192, Opus 128;
   SoundCloud — доступне AAC/інший дозволений потік.
6. ↓ залишається окремою дією завантаження через можливості провайдера.

## Оновлення розширень

Лише встановлені **наші модифіковані .sflx** Qobuz Online,
Jellyfin Online і SoundCloud Online з `fullTrackStreaming` захищені від
заміни через **будь-який репозиторій**. Навіть якщо Repo показує нову
версію, Mornye Play не завантажуватиме її поверх встановленого мода.

- **Звичайні розширення** з `https://github.com/mornyeapp/Mornye-Extension`
  продовжують оновлюватися без обмежень.
- Звичайні Qobuz, Jellyfin і SoundCloud **без** ознаки нашого мода також
  оновлюються як раніше.
- Захист діє і для тимчасово вимкненого модифікованого розширення.
- Щоб оновити **нашу модифікацію**, встановіть новий перевірений файл
  через **Settings → Extensions → Install .sflx**.
- Видалення модифікованого пакета повертає можливість установлювати
  звичайну версію цього розширення з Repo.

## Безпека та обмеження

- Jellyfin допускається лише через HTTPS: його API передає тимчасовий токен
  доступу всередині URL для плеєра. Mornye не зберігає такий URL у черзі
  чи метаданих, але URL може бути видимим локальному плеєру або серверним
  журналам. Використовуйте тільки довірений власний сервер і не діліться
  журналами з токенами.
- SoundCloud не надає Hi-Res FLAC цим методом; деякі композиції можуть мати
  лише HLS, залежати від регіону або не бути доступними для стороннього
  відтворення. Якщо HLS не підтримується аудіодвигуном, така композиція
  не відтвориться.
- DRM, платні права доступу, географічні обмеження чи перевірки підписаної
  сесії не обходяться. Цей мод не надає доступу до недозволених потоків.
- Фактичне відтворення й перемикання на Android ще потребують тесту
  на пристрої; автоматичні тести перевіряють структуру та маршрутизацію.
- Старі APK із тим самим package ID, але іншим ключем підпису, можуть
  вимагати перевстановлення. Збережіть налаштування перед заміною.
