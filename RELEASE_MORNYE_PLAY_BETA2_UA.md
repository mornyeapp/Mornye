# Mornye Play v5.3.1 — Beta 2

**Статус:** APK і розширення зібрані та перевірені; автоматичне створення GitHub Release наразі заблоковано дозволами GitHub Actions (HTTP 403 на створення тегів і релізів).

**Назва застосунку:** Mornye Play  
**Android package ID:** `com.famous37.mornyeplay`  
**Версія:** 5.3.1  
**Архітектура:** ARM64  
**Тег для публікації:** `mornye-play-v5.3.1-beta.2`

## Що нового

- **Suggested songs:** ▶ відтворює повну композицію замість короткого прев'ю; ↓ завантажує трек; + додає до плейлиста.
- **Popular:** окремі кнопки ▶ і ↓ біля кожної пісні; натискання на назву запускає відтворення.
- Старі кнопки прев'ю переведено на повне локальне або онлайн-відтворення.
- Окремі ▶ та ↓ у головному розділі, пошуку, альбомах і плейлистах.
- Вибір якости онлайн-аудіо довгим натисканням ▶; якости завантаження — довгим натисканням ↓.
- FLAC/Hi-Res, черга, автоматичний перехід між треками, технічні параметри за наявности достовірних даних.
- **Окреме встановлення:** `com.famous37.mornyeplay` дає змогу використовувати програму поруч з оригінальним Mornye.

## Установлення

1. Завантажте `Mornye_Play_v5.3.1_ARM64.apk` з успішної [Android-збірки](https://github.com/famous37/Mornye/actions/runs/43297523551).
2. Установіть APK. Дані Beta 1 з іншим package ID не переносяться.
3. У новому застосунку встановіть і ввімкніть `Mornye_Qobuz_Online_v1.2.29.sflx` з успішної [збірки розширення](https://github.com/famous37/Mornye/actions/runs/43286702448).
4. Для завантажень налаштуйте доступний авторизований музичний провайдер.

**Beta:** APK пройшов автоматичну Android-збірку, статичний аналіз, перевірку цифрового підпису та перевірку package ID. Повне онлайн-відтворення, автоматичний перехід і завантаження потребують тестування на пристрої. Модифікація не є офіційним застосунком Qobuz.
