# Mornye Play — незалежний музичний застосунок для Android

**Статус:** експериментальна збірка ARM64 на основі Mornye 5.3.1.

## Окреме встановлення

- Назва застосунку: **Mornye Play**
- Ідентифікатор Android: `com.famous37.mornyeplay`
- Офіційний Mornye: `com.zarz.mornye`
- Обидва застосунки встановлюються паралельно й мають окремі налаштування, розширення, облікові дані та локальну бібліотеку.
- Внутрішній Kotlin namespace лишається `com.zarz.mornye` для сумісности з нативними компонентами. Це **не** ідентифікатор встановленого застосунку.
- Mornye Play — незалежна неофіційна модифікація, не пов'язана з Qobuz або розробниками оригінального Mornye.
- Для встановлення майбутніх версій поверх попередніх потрібен **один постійний ключ підпису APK**. Без нього може знадобитися перевстановлення із втратою внутрішніх даних.

## Повне відтворення замість прев'ю

- Старі елементи `PreviewButton` відтворюють повну композицію через основний плеєр: спочатку локальний файл, а за його відсутности — доступний онлайн-потік. Короткий `previewUrl` більше не використовується.
- **Suggested songs:** ▶ повний трек, ↓ офлайн-завантаження, + додавання до плейлиста. Натискання на назву запускає відтворення.
- **Popular:** ▶ повний трек та ↓ завантаження біля композицій, натискання на рядок запускає відтворення, довге натискання відкриває додаткові дії.
- На головній сторінці, у пошуку, альбомах і плейлистах збережено прямі кнопки ▶ і ↓.
- Довге натискання ▶ — вибір якости онлайн-відтворення; довге натискання ↓ — вибір якости завантаження.
- Параметри FLAC та бітрейт відображаються тільки за наявности достовірних даних.

## Установлення

1. Завантажте APK `Mornye_Play_v5.3.1_ARM64.apk` з успішного релізу Mornye Play.
2. Установіть його поруч з офіційним Mornye.
3. У новому застосунку встановіть і ввімкніть розширення `Qobuz Online v1.2.29.sflx`, якщо використовуєте підтримуваний онлайн-провайдер.
4. Для завантажень налаштуйте доступний авторизований провайдер.

## Обмеження

- Експериментальний онлайн-провайдер не гарантує доступу до всіх композицій або режимів Hi-Res.
- Модифікація не обходить підписок, автентифікації чи технічного захисту музичних сервісів.
- Новий package ID означає, що дані попередньої Beta-версії не переносяться автоматично.
- Для деяких спільних посилань або OAuth-зворотних викликів Android може запропонувати вибрати застосунок.
- Успішна Android-збірка не замінює перевірки на телефоні: особливо автоматичного переходу між треками, чинности підписаних URL та офлайн-завантажень.
